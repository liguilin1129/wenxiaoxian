# 五育圆形雷达仪表盘

- 在“我的 → 成长银行 → 数据板”内，将五育横向进度条替换为圆形底盘、四层圆形网格、五条数据轴及紫色数据区域。
- 数据板默认首屏最上方展示仪表盘，位于积分余额、切换栏及挑战入口之前；使用浅紫渐变卡片和突出标题。切换成长记录或流水时隐藏仪表盘，避免妨碍操作，不重复渲染两份图表。
- 固定顺序：德育、智育、体育、美育、劳育。周围显示各维度名称及实际积分。
- 继续使用既有 `bank.overview().dimensions`：只统计成长银行的确认入账及冲正流水，不将旧四维任务强行映射为五育，不修改积分或账务。
- 100 分是原有展示基准，并非能力评价；图形最高显示到外圈，超过基准的实际积分仍完整显示。没有记录时各轴为零，不填入示例能力值。
- 按用户要求，页面移除图表底部统计口径说明及零数据提示小字；口径保留在本文档，零数据直接以五轴零值展示，绘制失败提示仍保留。
- 使用原生 Canvas 2D，按设备像素比绘制；数据更新、组件重建及窗口变化时重绘，失效回调不绘制已销毁组件。
- 图表绘制失败时提供五育数值文字兜底。
- 本轮仅修改五育图表，不新增官方商城或积分银行入口，不扩展挑战业务闭环。

## 验收

在 `miniapp/` 目录运行 `node ../test-data/miniapp-tests/acceptance.js`，包含五轴几何、零值／异常值、超过上限、绘制指令、像素比、数据更新、尺寸变化、回调失效与文字兜底的模拟测试。

微信开发者工具与真机仍需检查：圆形不变形、五个名称及分数不被裁切；确认记录和冲正后图形更新；切换数据板／成长记录及重新进入后正常重绘；零数据明确展示；不同屏幕宽度与横竖屏正常。
