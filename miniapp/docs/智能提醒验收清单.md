# 智能提醒（2026-10-21）

## 本轮实现

- 根据当前未完成任务生成今日待办、今天／明天到期、集中补卡提醒。
- 优先级：今天到期 → 明天到期 → 今日待办 → 集中补卡 → 家长原有会议／初评提醒。
- 今日待办是一条任务总数摘要，到期提醒是具体任务，两者可能对应同一任务，提醒条数不等于任务数。
- 点击到期提醒进入任务详情；今日待办进入打卡页；补卡提醒进入集中补卡页。
- 阅读不等于完成：移除标记已读按钮，不再点击即隐藏未完成任务。旧已读状态不会屏蔽任务提醒。
- 页面重新展示时刷新，前台每分钟刷新；离开页面停止计时，跨日自动重新计算。
- 首页智能提醒卡及金句下方原有提醒区域使用同一摘要，保留原有首页结构。
- 首页两处摘要均最多展示优先级最高的两条：有一条仅显示一条，无提醒显示空态，不用虚构内容补足两条；点击可进入完整提醒页。窄卡长文本单行省略，避免挤占任务中心。
- 家长保留会议与初评提醒；孩子可访问智能提醒，但只展示任务、到期和补卡提醒。
- 未登录清空提醒内容；没有事项时显示“暂无提醒”。
- 不接入 AI、订阅消息或付费功能，个性化提醒仍为待配置入口。

## 自动化验收

在 `miniapp/` 目录运行 `node ../test-data/miniapp-tests/acceptance.js`，共 8 组测试。

提醒专项：在 `miniapp/` 目录运行 `node -r ../test-data/miniapp-tests/resolve-miniapp.js ../test-data/miniapp-tests/reminders.test.js`，覆盖优先级、日期边界、任务修改／完成／删除、已读与重启、失效点击、模式切换、首页同源摘要、定时器释放、未登录及空态。

以上是在 Node 内存模拟环境中验证，不读取真实微信缓存，不代表微信编译、云端与真机已通过。

## 微信开发者工具及真机待验收

- [ ] 编译后进入首页和智能提醒页，无控制台错误。
- [ ] 分别验证 0、1、2、3 条提醒：首页最多显示两条，有一条只显示一条，三条以上可进入提醒页查看全部；未登录不保留之前的预览。
- [ ] 新增今天截止任务，首页优先展示该任务，点击提醒进入正确详情。
- [ ] 仅查看后返回，未完成任务仍提醒；完成后返回，到期提醒消失、待办数量减少。
- [ ] 新增明天截止任务，排在今天截止任务之后；删除后提醒同步消失。
- [ ] 切换孩子模式仍可进入提醒页，但不显示会议与初评；切回家长模式恢复对应提醒。
- [ ] 无待处理事项显示“暂无提醒”；退出登录不残留上一用户内容。
- [ ] 验证补卡资格成立时跳转正确，补卡完成后该提醒消失（使用独立测试数据）。
- [ ] 真机检查首页窄卡两行省略、提醒长任务名换行、底部安全区及返回刷新。
