# 框架搭建后完善待办清单

用途：记录整体框架搭建完成后需要补齐的开发闭环，不是小程序内的任务功能，也不会生成孩子的任务或提醒。

## 1. 挑战功能闭环完善

- [ ] 待整体框架搭建完成后开展。
- 当前进度：首页“挑战”入口、“我的 → 成长银行”中的官方挑战与家庭自定义挑战入口、共用的挑战活动分类页面已搭建；尚未实现完整业务闭环。
- 后续完善范围：官方挑战发布与展示、家庭自定义挑战、参与与打卡、进度追踪、完成判定、奖励发放与记录查询。
- 衔接要求：复用已有任务打卡与积分记录，避免重复打卡、重复发奖；明确家长与孩子模式的操作范围。
- 验收目标：从选择／创建挑战，到参与、执行、完成、奖励入账与历史查询，能够完整跑通。
- 具体规则及实现方案在开展本项时再确认，本次仅记录待办，不启动开发。

## 2. 商城商品完善

- [ ] 待整体框架搭建完成后开展。
- 当前进度：首页两列商品展示、“我的”页面商城入口、商城首页及商品详情框架已搭建；尚无真实商品，交易能力未接入。
- 后续完善范围：真实商品资料、图片、人民币价格、商品详情与上架状态；下单、支付、订单、物流及售后闭环的具体方案届时确认。
- 导航要求：点击首页商品进入对应详情，返回时进入商城首页；从商城列表也可进入商品详情，返回后不得自动重新打开详情。
- 衔接要求：官方现金商城与原有家庭积分兑换保持独立，不改变现有积分商城规则。
- 验收目标：商品信息真实完整、首页与商城数据一致，详情与返回路径正确；交易能力接入后另行完成全流程验收。
- 本次仅记录待办，不启动进一步开发。
