# 官方商城展示框架

- 首页“今日金句推荐”下方新增两列精选商品展示区，可进入官方商城子页面。
- “我的”页面新增独立商城区域，游客与已登录用户均可浏览入口。
- 官方商城使用人民币商品体系；原有奖励兑换／积分商城及其积分规则不变。
- 本轮没有真实商品数据：共享商品目录为空，首页显示两个“商品待上架”卡位，商城显示“暂无在售商品”，不虚构商品、价格和销量。
- 已搭建商品详情页，展示图片、名称、人民币价格及商品介绍；失效商品展示不可用状态。尚不包含购物车、下单、支付、订单、物流和售后。
- 首页点击真实商品后，先在页面栈保留商城首页，再自动打开对应详情；按原生返回或“返回商城”按钮均回到商城，不直接回到小程序首页。商城自动跳转只执行一次，避免返回后重新进入详情。点击“全部商品”、“我的”商城入口或待上架卡位则正常进入商城首页。
- 模拟验收：在 `miniapp/` 目录运行 `node ../test-data/miniapp-tests/acceptance.js`；尚需在微信开发者工具及真机检查两列布局、长文本、安全区和首页／我的入口跳转。
- 未更改真实积分、商品或云端数据，未提交／推送 GitHub。
