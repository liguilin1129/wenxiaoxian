# 简洁微信登录页

- 修改前提交：`f19777c`，已推送 `origin/main`。
- 备份包含目录重组、小程序与后台现有开发成果，保留原有商城模拟测试失败，不作为验收发布版。

## 页面

- 白底、应用标识及名称、绿色“微信登录”按钮、“暂不登录”。这是应用自有登录页，不是微信系统授权弹窗，也不是微信客户端登录页。
- 默认不展示表单；头像和昵称可展开后主动填写，不再强制填昵称后才能登录，不索取手机号。
- 不预勾协议，不放置虚假的协议链接；正式上线前应按实际数据处理行为配置并审核小程序隐私保护指引。
- 资料选择仍沿用现有能力，头像临时路径的正式持久化上传不在本轮完成范围内。

## 登录逻辑

- 正式按钮使用 `wx.login` 后调用既有服务端认证接口，云托管模式仍通过现有 `cloudHosting.request` 访问 `/api/auth/wechat/login`。
- 仅在服务端返回成功、用户标识及令牌后保存会话；昵称可由服务端使用“微信用户”默认值。
- 服务失败不再退回本地登录，不会把认证失败展示为成功。真实可用性取决于已部署登录服务与云托管权限配置，本轮未部署服务。
- 原有本地登录保留为独立“开发预览（不验证微信身份）”按钮，仅开发版本显示且执行时再次检查环境；体验版和正式版不显示、不放行。
- 开发预览清除旧服务端令牌，避免带着旧令牌误用模拟身份；但仍是现有本地开发状态，不是独立安全沙箱，不应在真实家庭数据上混用。
- “暂不登录”只返回首页，不写入登录标记，不清除现有用户数据。
